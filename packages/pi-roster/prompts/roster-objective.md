Submit this objective with the extension command `/roster-code $ARGUMENTS`.
Roster owns worker demand, topology, task scheduling, receipts, budgets, Git
frontier acceptance, conflicts, and certification. Stay attached to the
returned run and report its durable status; do not duplicate its orchestration
inside Pi.
